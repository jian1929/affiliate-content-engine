📧 Email Client Setup Guides

  1. Go to Gmail Settings → See all settings → General → Signature
  2. Click "Create new" or select an existing signature
  3. Delete any existing content
  4. Click Insert signature → From messages (or paste directly)
  5. For HTML signatures: Click the link icon to add hyperlink to your CTA text
  6. Set signature as default for new emails and replies/forwards
  7. Click "Save Changes"
  1. Go to Outlook → File → Options → Mail → Signatures
  2. Click "New" to create a new signature
  3. Name your signature (e.g., "Affiliate Links")
  4. Paste your HTML signature in the text box
  5. To add links: Select text → Right-click → Edit Link → paste URL
  6. Set as default signature for new emails
  7. Click "OK" to save
  1. Open Mail → Preferences → Signatures
  2. Click the + button to add a new signature
  3. Name your signature
  4. Paste your signature content in the right pane
  5. To add links: Select text → Edit → Add Link → paste URL
  6. Drag signature to account to assign
  7. Close Preferences - auto-saves
  1. Go to Thunderbird → Tools → Account Settings → Signatures
  2. Select your email account
  3. Check "Attach signature from a file instead"
  4. Click "Choose File" to link an HTML file OR
  5. Check "Use HTML" and paste your signature in the text box
  6. Click "OK" to save
  1. Go to Yahoo Mail → Settings → More Settings → Writing email
  2. Scroll to "Signature" section
  3. Toggle "Signature" ON
  4. Paste your signature text or HTML
  5. Click "Save" to apply

💡 Pro Tips for Maximum Clicks

📈 Change articles weekly

Keep it fresh by rotating different articles. This tests what converts best and prevents email fatigue.

🎯 Use action-oriented CTA

"Free Guide →" performs better than just a link. Create urgency with words like "Limited" or "Exclusive."

📧 BCC yourself test

Send a test email to yourself with the signature. Check how it renders in different email clients.

🔗 Track with UTM

Add ?utm_source=signature&utm_medium=email to your links to track which emails drive the most clicks.
