GitHub Actions Setup

Enable automated posting workflow

After getting credentials, add them to GitHub:

  1. Go to your GitHub repo: github.com/YOUR_USERNAME/affiliate-content-engine
  2. Click "Settings" → "Secrets and variables" → "Actions"
  3. Click "New repository secret" for each credential

Secrets to add:

TWITTER_API_KEY=your_twitter_api_key
TWITTER_API_SECRET=your_twitter_api_secret
TWITTER_ACCESS_TOKEN=your_twitter_access_token
TWITTER_ACCESS_SECRET=your_twitter_access_secret
REDDIT_CLIENT_ID=your_reddit_client_id
REDDIT_CLIENT_SECRET=your_reddit_client_secret
REDDIT_USERNAME=your_reddit_username
REDDIT_PASSWORD=your_reddit_password
🔐 Open GitHub Secrets

🎉 Automated Traffic Enabled!

Your credentials are saved. GitHub Actions will now post to Twitter and Reddit twice daily (9 AM and 6 PM UTC).
