API Method 3: Medium API (For Developers)

Medium has an API for cross-posting. Requires getting a integration token from your Medium settings.

API Endpoint

POST https://api.medium.com/v1/users/{userId}/posts
Authorization: Bearer {accessToken}
Content-Type: application/json

{
  "title": "Article Title",
  "contentFormat": "markdown",
  "content": "# Article Content...",
  "tags": ["amazon", "ecommerce", "selling"],
  "canonicalUrl": "https://your-site.com/article",
  "publishStatus": "public"
}

Get your integration token: medium.com/me/settings → Integration Tokens
